# LOAN_DATA_EXPLORATION
Built a machine learning model to predict loan approval based on applicant details. Performed data cleaning, feature encoding, model comparison, and evaluation using real-world loan data.
## Loan Approval Prediction (Machine Learning)

Built a machine learning model to predict loan approval based on applicant details.

### Tech Stack
- Python, Pandas, NumPy
- Scikit-learn, Matplotlib

### Models Used
- Logistic Regression
- Random Forest

### Key Insights
- Credit history is the strongest predictor
- Logistic Regression outperformed Random Forest on this dataset

### Result
- Accuracy ~79%
- Practical business insights for banking decisions
